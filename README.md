# EjercicioJavaFX

## Funcionalidad
Aplicación de registro de Tareas desarrollada en JavaFX. Esta aplicación permite a los usuarios agregar, eliminar y marcar tareas como completadas, proporcionando una interfaz intuitiva y fácil de usar.

### Tecnologías utilizadas
- Java
- JavaFX

### Componentes utilizados
- Stage
- Scene
- Button
- TextField
- Label
- ListView
- HBox
- VBox
- BorderPane
